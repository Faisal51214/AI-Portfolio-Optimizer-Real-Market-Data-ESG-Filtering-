# AI-Portfolio-Optimizer-Real-Market-Data-ESG-Filtering-
This project builds an AI-driven portfolio optimizer using real historical data from Yahoo Finance. It offers full return modeling, risk estimation and ESG-based filtering before constructing an optimal portfolio using modern portfolio theory.

# Features
• Real market data through yfinance
• Automatic cleaning and validation
• Daily and annualized return calculations
• Covariance matrix modeling
• ESG threshold filter
• Maximum-Sharpe optimization
• Visualizations: volatility vs return, efficient frontier, allocation
• Exportable results and PDF report

# How It Works
Download daily closing prices for a basket of global assets
Compute returns and risk metrics
Filter out low-ESG assets
Optimize weights using Markowitz mean-variance optimization
output the final optimized portfolio and performance metrics

# Results Summary
• Expected return: 0.1%
• Expected volatility: 1.53%
• Sharpe ratio: 0.0645
• ESG filter: applied at ≥70 threshold

These results reflect a conservative, ESG-aligned portfolio.
